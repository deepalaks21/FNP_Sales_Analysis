# FNP Sales Analysis – Excel Dashboard

## 📌 Project Overview

This project analyzes FNP sales data using Microsoft Excel to understand sales performance, customer behavior, product categories, occasions, and delivery performance.

## 🛠️ Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Dashboard

## 📊 Key Analysis

* Total Sales
* Total Orders
* Quantity Sold
* Sales by Category
* Sales by Occasion
* Monthly Sales
* Product Performance
* Delivery Analysis

## 📈 Dashboard

Created an interactive Excel dashboard using KPIs, charts, Pivot Tables, and filters to visualize business insights.

## 🎯 Objective

To transform raw sales data into meaningful business insights using Excel data cleaning, analysis, and visualization.
